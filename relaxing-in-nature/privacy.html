Privacy Policy

Relaxing in Nature Uploader · Last updated: October 11, 2026

Relaxing in Nature Uploader is a private tool used only by the owner of the YouTube channel RelaxingInNature to manage videos on their own channel.

What the app accesses

With the owner's permission (Google sign-in), the app uses the YouTube Data API to upload videos and thumbnails, set video titles, descriptions, tags and publish times, and add videos to playlists on the owner's own channel.

What the app stores

The sign-in token is stored only on the owner's own computer so uploads can run without signing in each time. The app does not collect, store, sell or share personal data of any other person, and it does not read viewers' data.

Sharing

No data is shared with third parties. Videos are sent only to YouTube.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
